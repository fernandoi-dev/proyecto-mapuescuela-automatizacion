# Sistema de Gestión de Ventas - Mapuescuela 📚

Este repositorio contiene la entrega del proyecto de integración de plataformas para la automatización del proceso de ventas de Mapuescuela.

## 👥 Equipo de Trabajo
* **[TU NOMBRE AQUÍ]**: Líder BPMN & Flowable (Modelado de procesos, diagramas AS-IS / TO-BE y automatización).
* **Andrés Araya**: Líder Backend & Gestión (Desarrollo de API REST y base de datos).

## 📂 Estructura del Proyecto
* `/backend`: Código fuente de los servicios REST (Java/Spring Boot) y scripts de Base de Datos.
* `/procesos_BPMN`: Archivos ejecutables `.bpmn` del modelo TO-BE.
* `/evidencias`: Capturas de ejecución de Flowable, pruebas en Postman (Status 200 OK) y enlaces al video técnico.

## 🚀 Tecnologías Utilizadas
* **Motor BPMN:** Flowable
* **Backend:** Java 17 / Spring Boot
* **Base de Datos:** MySQL
* **Pruebas de API:** Postman
